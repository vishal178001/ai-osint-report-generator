# Security Policy

## Responsible use

This project performs OSINT and security analysis against domains. Only use it against systems and domains you own or have explicit permission to assess.

## Reporting a vulnerability

Please do not disclose sensitive vulnerability details in a public GitHub issue.

If you discover a security issue in the project itself, contact the repository maintainer privately through the contact information available on the maintainer's GitHub profile.

When reporting an issue, include:

- A short description of the vulnerability
- The affected component or file
- Steps to reproduce, where safe
- Potential impact
- A suggested remediation, if known

Please do not include secrets, credentials, personal data, or sensitive target information in the report.
